# QORGAU AI — Цифрлық дәуірдегі құқықтық сауаттылық

Ғылыми жоба сайты: «Цифрлық дәуірдегі құқықтық сауаттылық: әлеуметтік желілер мен жасанды интеллектіні қауіпсіз пайдаланудың құқықтық негіздері».

## Мазмұны
- Жобаның мақсаты, өзектілігі, ғылыми жаңалығы, аннотация (қазақ / орыс / ағылшын)
- «Цифрлық із» интерактивті тізбегі
- Қазақстан заңнамасы және халықаралық тәжірибемен салыстыру
- Адам бақылауының үш деңгейі, алгоритмдік әділдікті бағалау
- Сауалнама қорытындылары
- Авторлық «Адам – Алгоритм – Құқық» үштағаны
- «Алгоритмдік құқықтық қауіпсіздік паспорты» генераторы
- «QORGAU AI» цифрлық құқықтық көмек платформасының прототипі
- Ұсыныстар және пайдаланылған әдебиеттер
